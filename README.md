# Emaily

Emaily is an Express server currently deployed on Render.

## Live server

https://emaily-g0ur.onrender.com/

## Endpoints

- `GET /` - server health response
- `GET /hello` - sample response

## Run locally

```bash
cd server
npm install
npm start
```

The server uses the `PORT` environment variable when provided and defaults to port `5000`.
